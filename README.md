# Ninja

A journaling app I'm building to write or speak my thoughts and get a short weekly summary of how my week went.

I'm building it as a monorepo with a React Native app and a Spring Boot API, mostly to get more hands-on with the full stack outside of web apps.

## What it does (so far)
Nothing yet. I'm starting with the API and will add the app after that.

## What I want it to do
- Save text entries, and later voice entries
- Tag each entry with a mood
- Generate a weekly summary using the Claude API
- Work offline and sync when there's a connection

## Stack
- Mobile: React Native (Expo), TypeScript
- Backend: Java 21, Spring Boot, PostgreSQL
- AI: Claude API

## Layout
- `api/` is the Spring Boot backend
- `mobile/` is the Expo app
- `docs/` holds notes on design decisions
